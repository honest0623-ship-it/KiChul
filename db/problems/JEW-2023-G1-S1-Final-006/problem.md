## Q
이차부등식
\[
x^2+kx+k+3\le 0
\]
에 대하여 해를 갖지 않도록 하는 정수 \(k\)의 최댓값을 \(A\)라고 하고, 모든 실수 \(x\)에 대하여 이차부등식
\[
x^2+px+p+3\ge 0
\]
이 성립하도록 하는 정수 \(p\)의 최댓값을 \(B\)라고 하자. 이때 \(A\), \(B\)의 값은?

## Choices
① \(A=5,\ B=5\)
② \(A=5,\ B=6\)
③ \(A=6,\ B=5\)
④ \(A=6,\ B=6\)
⑤ \(A=6,\ B=7\)

## Answer
②

## Solution
\[
x^2+kx+k+3\le 0
\]
이 해를 갖지 않으려면, 위로 열린 이차식이 항상 양수가 되어야 하므로 판별식이
\[
D<0
\]
이어야 한다.

따라서
\[
k^2-4(k+3)<0
\]
\[
k^2-4k-12<0
\]
\[
(k-6)(k+2)<0
\]
이므로
\[
-2<k<6
\]
이다.

정수 \(k\)의 최댓값은
\[
A=5
\]
이다.

또
\[
x^2+px+p+3\ge 0
\]
이 모든 실수 \(x\)에 대하여 성립하려면 판별식이
\[
D\le 0
\]
이어야 한다.

따라서
\[
p^2-4(p+3)\le 0
\]
\[
p^2-4p-12\le 0
\]
\[
(p-6)(p+2)\le 0
\]
이므로
\[
-2\le p\le 6
\]
이다.

정수 \(p\)의 최댓값은
\[
B=6
\]
이다.

따라서 정답은 ②이다.
