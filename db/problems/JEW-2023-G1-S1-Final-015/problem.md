## Q
임의의 정수 \(a\)에 대하여 부등식
\[
\left|x-a+1\right|+\left|x-a-1\right|\le k
\]
를 만족시키는 정수의 개수가 \(7\)개가 되도록 하는 모든 정수 \(k\)의 합은?

## Choices
① \(10\)
② \(11\)
③ \(12\)
④ \(13\)
⑤ \(14\)

## Answer
④

## Solution
\[
y=x-a
\]
라고 두면 주어진 부등식은
\[
\left|y+1\right|+\left|y-1\right|\le k
\]
가 된다.

이 식은 \(a\)와 무관하므로 정수해의 개수는 \(y\)에 대하여 구해도 된다.

\[
\left|y+1\right|+\left|y-1\right|
\]
의 값을 구간별로 정리하면
\[
y\le -1 \text{ 일 때 } -2y,
\]
\[
-1\le y\le 1 \text{ 일 때 } 2,
\]
\[
y\ge 1 \text{ 일 때 } 2y
\]
이다.

따라서 정수해의 개수를 세어 보면
\[
k=2,\ 3 \text{ 일 때 } 3\text{개}
\]
\[
k=4,\ 5 \text{ 일 때 } 5\text{개}
\]
\[
k=6,\ 7 \text{ 일 때 } 7\text{개}
\]
이다.

그러므로 가능한 정수 \(k\)는
\[
6,\ 7
\]
이고, 그 합은
\[
13
\]
이다.
