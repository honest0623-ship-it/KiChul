## Q
연립부등식
\[
\begin{cases}
x^2-12x+32\le 0 \\
x^2-ax-2a-4\le 0
\end{cases}
\]
의 정수인 해가 1개뿐일 때, 실수 \(a\)의 값의 범위는?

## Choices
① \(2\le a<3\)
② \(2<a\le 3\)
③ \(2\le a\le 3\)
④ \(3<a\le 4\)
⑤ \(3\le a\le 4\)

## Answer
①

## Solution
첫 번째 부등식은
\[
x^2-12x+32=(x-4)(x-8)
\]
이므로
\[
4\le x\le 8
\]
이다.

두 번째 부등식은
\[
x^2-ax-2a-4\le 0
\]
\[
x^2-4\le a(x+2)
\]
이다.

위에서 \(4\le x\le 8\)이므로
\[
x+2>0
\]
이고, 양변을 \(x+2\)로 나누면
\[
a\ge \frac{x^2-4}{x+2}=x-2
\]
이다.

따라서 정수해 \(x\)는
\[
4\le x\le 8,\qquad x\le a+2
\]
를 만족해야 한다.

이때 가능한 정수 \(x\)를 차례로 보면
\[
x=4 \text{ 이려면 } a\ge 2
\]
\[
x=5 \text{ 이려면 } a\ge 3
\]
이다.

정수해가 1개뿐이려면 \(x=4\)만 가능해야 하므로
\[
2\le a<3
\]
이다.
